# Minuutje: голландский на слух (A1–A2)

Короткие тексты с озвучкой, синхронной подсветкой слов, проигрыванием отдельного слова, предложения или абзаца, цветовой подсветкой частотности и русским переводом.

## Запуск

```sh
npm install
npm run dev        # http://localhost:4321
npm run build      # статический сайт в dist/
```

Пайплайн (Python 3.12+, uv): `cd pipeline && python -m uv sync`

## Как добавить урок

1. Создать папку `content/inbox/<slug>/`. Чтобы урок открывался по теме на главной, `<slug>` должен совпадать со slug темы из [src/data/topics.ts](src/data/topics.ts): английское название в нижнем регистре через дефис, например `airports`, `bad-habits`, `valentines-day-love`. Уроки без темы попадают в блок «Другие уроки».
   - `meta.json`: `{"title": "...", "level": "A1", "topic": "...", "order": 2}`
   - `nl.txt`: текст на голландском, абзацы разделены пустой строкой
   - `en.txt`, `ru.txt`: переводы с теми же абзацами. Если в абзаце совпадает число предложений, перевод показывается под каждым предложением, иначе под абзацем
   - `audio.mp3` (или wav/m4a/ogg…), необязательно. Без него озвучка делается через TTS
   - `align.txt`: соответствие слов для подсветки перевода при наведении, необязательно. Блоки `# N` по предложениям, строки `голландское = английское = русское`, например `vraag me af = wonder = Интересно` (подробнее в [pipeline/wordalign.py](pipeline/wordalign.py))
2. `npm run lesson -- <slug>`. Урок озвучивается всеми голосами из `VOICES` в [pipeline/audio.py](pipeline/audio.py) (сейчас Fenna и Maarten; первый — по умолчанию). Опции: `--voices fenna`, `--rate -10%`, `--tts`
3. Скрипт выводит новые леммы без перевода (`Unglossed vocab keys`). Переводы вписываются в `src/data/vocab.json` (поле `ru`)
4. Если spaCy ошибся с леммой или частью речи, добавить в `meta.json`:
   `"overrides": {"ontbijt": {"lemma": "ontbijten", "pos": "VERB"}}` и пересобрать урок
5. Разбор по членам предложения (кнопка «Разбор») строится автоматически из синтаксического дерева spaCy ([pipeline/syntax.py](pipeline/syntax.py)). Ошибки исправляются в `meta.json`:
   `"syntax": {"9:ontbijt": "P", "7:goedemorgen": "O", "5:te": "-"}` — номер предложения в уроке, слово → `S` подлежащее, `P` сказуемое, `O` дополнение, `A` определение, `D` обстоятельство, `-` без подчёркивания

### Свои аудиозаписи

Нужны ffmpeg (`winget install Gyan.FFmpeg`) и тяжёлые зависимости для forced alignment (torch, модель MMS):
`cd pipeline && python -m uv sync --extra align`

Текст в `nl.txt` должен совпадать с тем, что произнесено.

## Устройство

- `pipeline/`: spaCy (`nl_core_news_md`) для лемм и отделяемых глаголов, wordfreq (Zipf) для частотности, edge-tts для озвучки с таймингами слов, ctc-forced-aligner для своих записей. `timing.py` переносит тайминги на токены через сравнение символов.
- `src/content/lessons/*.json`: готовые уроки (схема в `src/content.config.ts`).
- `src/components/Reader.tsx`: Preact-ридер. Проигрывание идёт диапазонами с точкой остановки, повтор зацикливает диапазон, в интервале 30 мс обновляется подсветка.
- Клик по слову проигрывает отдельно озвученный клип (`public/audio/words/`, создаётся пайплайном для каждой словоформы и переиспользуется между уроками). Слово, вырезанное из слитной речи, всегда цепляет соседей. Кнопка «▶ в тексте» в карточке вырезает слово из аудио урока через Web Audio, граница подтягивается к ближайшему минимуму громкости ([src/lib/wordAudio.ts](src/lib/wordAudio.ts)).
- Прогресс, «Мои слова» и настройки хранятся в `localStorage`.

Полосы частотности (Zipf): ≥5.5 Основа, 4.5–5.5 Важное, 3.5–4.5 Полезное, <3.5 Редкое.

Аудио кодируется с постоянным битрейтом (CBR): так браузер точно перематывает к отдельному слову. Не перекодируйте в VBR.
